# Grand Theft Snodland

A small-scope, top-down 3D open-world game set in a stylised but geographically recognisable Snodland, Kent.

Inspired by the elevated, semi-angled presentation of GTA Bridgwater. The priority is a playable opening sequence, not a sprawling feature list.

## Project direction

- **Engine:** Godot 4
- **Language:** GDScript
- **Camera:** Elevated, semi-angled top-down 3D
- **Targets:** PC and Android, with browser export investigated
- **World:** Real Snodland geography, using OpenStreetMap data with appropriate attribution
- **Art approach:** Lightweight procedural/placeholder 3D assets first. Blender modelling is deferred.

## First playable milestone: A New Start

1. The player arrives at Snodland railway station.
2. A brief freeze-frame phone message introduces the town and explains that money has been sent.
3. The starting money can only be used to rent the starter flat above a High Street shop.
4. The map points the player towards the High Street.
5. A glowing marker outside the shop lets the player rent the flat.
6. The mission completes and the flat becomes the save point.
7. The player can return home to save progress.

The initial playable world should cover Snodland, including Holborough, bounded approximately by the A228 roundabout-to-roundabout stretch and St Benedict's Road.

## Development rule

Keep the first build small. Prioritise the map, player, basic NPCs and cars, then implement the opening mission. Defer unrelated systems until this sequence works.
